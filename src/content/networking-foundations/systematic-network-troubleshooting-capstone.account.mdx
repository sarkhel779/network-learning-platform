<h2 id="guided-branch-incident">Guided branch incident</h2>

The branch portal has several sequential faults. State a hypothesis, predict what a safe test should show, collect evidence, and remediate only when the evidence supports the change. The next fault becomes visible only after the current layer is corrected.
