<h2 id="what-makes-a-device-a-host">What makes a device a host?</h2>

A **host** is an end device that can send, receive, or process network data. A desktop computer, laptop, phone, printer, camera, physical server, and cloud virtual server can all be hosts.

The shape of a device does not determine whether it is a host. Its network role does. **A printer with a network interface is a host.**

<h2 id="network-interfaces">Network interfaces</h2>

A host connects through a **network interface**. The interface may use a cable or a wireless radio. A device can have more than one interface, such as Ethernet and Wi-Fi, but each interface is a connection point rather than a separate user device.

Interfaces allow hosts to join a network. Detailed addressing and link behavior come later in the course.

<h2 id="clients-and-servers">Clients and servers</h2>

A **client** application asks for a service. A **server** application provides a service and responds to requests. When a browser asks a web service for a page, the browser is the client and the web service is the server.

Client and server describe application roles, not permanent categories of hardware. A large machine is not automatically a server, and a phone is not always only a client.

<h2 id="one-host-more-than-one-role">One host, more than one role</h2>

One host can run several applications at once. **The same computer can run a client application and serve a file to another device.** Its role depends on what each application is doing in that conversation.

A cloud server is still a host even though you may not see its physical machine. A network printer is also a host because it receives data through a network interface.
