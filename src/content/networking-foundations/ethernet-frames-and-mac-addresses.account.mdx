<h2 id="diagnose-frame-problems">Diagnose frame problems</h2>

Use evidence from the nearest observable layer:

1. Confirm the interface is up and has negotiated a usable link.
2. Check whether the expected frame leaves the source interface.
3. Read source, destination, EtherType and frame length.
4. Decide whether the switch should forward one copy or flood within the VLAN.
5. Check the receiving NIC and VLAN before blaming an upper-layer protocol.

<InterviewScenario prompt="A switch floods a frame whose destination is 02:00:00:00:00:99. Does this prove the sender used broadcast?">
No. The individual/group bit indicates a unicast destination. Flooding can occur because the switch does not yet have that destination in its MAC table. Verify the table and VLAN, then observe whether later frames become known unicast.
</InterviewScenario>
