<h2 id="what-a-router-does">What a router does</h2>

A **router** connects different IP networks. It gives devices on one network a way to reach devices on another network. A home router, for example, connects the home LAN to the provider's network.

A router is different from a switch. A switch mainly connects devices inside one local network; a router sits between networks.

<h2 id="router-interfaces">Router interfaces</h2>

A router has two or more network interfaces. Each interface joins a network and normally has an IP address that belongs to that network. The router provides a controlled connection between those sides.

The interfaces may be physical ports or logical interfaces. For this introduction, the important idea is that a router has a presence in every network it directly connects.

<h2 id="network-boundaries">Network boundaries</h2>

A boundary is the point between differently named IP networks. A router belongs at that boundary. Ordinary local traffic can remain within one network, while traffic that must leave uses a router.

Detailed path selection is covered in the Network Layer module. Here, focus only on where the router belongs and why it connects different networks.

<h2 id="default-gateway">The default gateway</h2>

A host's **default gateway** is normally a router interface on the host's own network. The host uses that gateway when it needs help reaching another network. The gateway is the first router, not necessarily the final destination.
