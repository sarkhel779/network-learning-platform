## Why network boundaries matter

Networks use boundaries to decide when traffic must leave the local link.

## What a router does

A router connects IP networks and selects a path for eligible packets.

## Local or remote?

The host applies its configured prefix before making this decision.

## The default gateway

The gateway is the local next hop for a remote destination.

## Direct delivery and routed delivery

Direct delivery reaches a local peer; routed delivery first reaches a router.

## What changes at each hop

Link-layer framing changes while end-to-end IP addressing stays stable when NAT is absent.
