<h2 id="what-is-a-router">What is a router?</h2>

A **router** is a network device that connects different IP networks. It gives devices on one network a doorway to another network. A home router, for example, connects a home network to an internet provider's network.

A switch mainly connects devices inside one local network. A router connects that network to other networks. Later modules will explain how a router chooses paths; for now, focus on its place between networks.

<h2 id="router-interfaces">Router interfaces</h2>

A router has two or more network interfaces. Each interface connects to a different network and normally has an IP address that belongs to that network.

Think of each interface as one side of a doorway. One interface may face the office network while another faces the internet provider.

<h2 id="routers-connect-networks">Routers connect networks</h2>

A network boundary is where one IP network ends and another begins. A router belongs at this boundary because it has an interface connected to each side.

For example, an office switch connects laptops and printers inside the Office LAN. A router then connects the Office LAN to the internet. Detailed forwarding decisions belong in the later Network Layer module.

<h2 id="routers-as-default-gateways">Routers as default gateways</h2>

A host's **default gateway** is normally the router interface on its own network. When a destination is outside the local network, the host sends the traffic to this gateway for help reaching the other network.

The default gateway is the first router on the journey. It is not the remote website or the final destination.
