<section id="interview-scenario">
  <InterviewScenario prompt="What happens after a user enters a website address?">
    Limit the answer to the concepts taught so far. A name must first be translated into a
    destination address; that translation is handled by DNS, which a later lesson will explain.
    Once the host has a destination IP address, it decides whether the destination is local or
    remote. For a remote destination, it learns the next-hop router's MAC address when needed,
    puts the packet into a frame, and sends that frame through the local medium.

    The switch forwards the frame using the destination MAC address. The router examines the
    destination IP address, selects a route, and creates a new frame for the next link. This
    repeats until the packet reaches the server's network. Application protocols, TCP, TLS, and
    the full DNS process add important steps, but they have not been taught fully yet, so this
    answer does not pretend to trace them.
  </InterviewScenario>
</section>
