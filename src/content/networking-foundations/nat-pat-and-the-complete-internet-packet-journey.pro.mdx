<h2 id="pro-u-turn-nat-lab">Pro U-Turn NAT lab</h2>

An internal client opens `10.0.0.25:51514 → 203.0.113.10:443`, although the HTTPS service is actually `10.0.0.50:443`. In the broken path, DNAT delivers the request but preserves the private client source. The server recognizes a directly reachable local peer and replies from `10.0.0.50:443`, producing a **mismatched peer tuple** for the session opened to the public address.

The working path uses **paired DNAT and SNAT**. DNAT selects the internal server, while SNAT makes the server return through the gateway. The gateway then reverses both translations so the client receives the response from `203.0.113.10:443`. Vendors may call this U-Turn NAT, hairpin NAT, NAT loopback, or NAT reflection.
