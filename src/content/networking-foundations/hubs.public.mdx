<h2 id="what-is-a-hub">What is a hub?</h2>

A **hub** is a simple device that connects several devices on one shared Ethernet segment. When a signal arrives on one port, the hub repeats that signal through every other active port.

<h2 id="why-hubs-existed">Why hubs existed</h2>

Early Ethernet networks needed an easy central connection point. A hub provided that physical meeting place without examining the information being carried.

Modern networks usually use switches instead because switches can be more selective. Hubs remain useful for understanding how shared early networks behaved.

<h2 id="shared-traffic-and-bandwidth">Shared traffic and bandwidth</h2>

All devices connected to a hub share the same communication space. Every repeated signal reaches the other connected devices, even when only one device is the intended receiver. The hosts must decide whether the received data is meant for them.

Because the connection is shared, simultaneous activity can interfere and available capacity is shared among the devices.
